# 今晚作业

四年级教学工具。错题只走三步：**先批改**（知道对错）→ **再讲解**（为什么、这一步怎么想）→ **再订正**（本子上改、自己说一遍、换一道、记住）。

## 教学闭环

```text
拍今晚那一页
    ↓
看图只拆题（题干 / 她写的字 / 竖式），模型不准打分
    ↓
本地验算、对课文原词、对本单元词表  →  对 / 错 / 不敢批
    ↓
对照过程 + 她以前的错  →  推断为什么会这样写
    ↓
先钉住这一步，再想开一点（不报本得数）
    ↓
写入错题记。同类错下次先调出来
```

模型负责**看见纸上有什么**。对错由规则判。错因由规则 + 记忆推断。讲解不给这题得数。方程 / 未知数直接停。

## 手机怎么用（自动批改）

电脑上启动看图服务（密钥只用本机的 `DASHSCOPE_API_KEY` 或 `~/.dashscope_key`，不进仓库）：

```bash
cd ~/今晚作业
python3 server.py
```

电脑和手机连**同一 Wi‑Fi**。手机 Safari / Chrome 打开：

`http://电脑的局域网IP:8787/`

例如 `http://192.168.1.108:8787/`

点 **「拍作业，自动批改」**。不要用微信。

GitHub Pages（https://zonglinxie-cyber.github.io/jinwan-zuoye/）只能用手写批改。自动看图必须走上面这个本机地址，或在设置里填写 `http://电脑IP:8787/api/see`。
