# 今晚作业

四年级亲子作业架：拍今晚老师布置的那张纸，**能验才判**，卡住只讲一步，她在本子上订正，同类题加重观察。孩子主操作，大人可插一句或稍后看一眼。

线上试玩（GitHub Pages）：

https://zonglinxie-cyber.github.io/jinwan-zuoye/

本机：

```bash
cd 今晚作业
python3 -m http.server 3002
```

打开 http://127.0.0.1:3002

## 2026 秋教材包

仓库里的 `kb/` 对齐 **2026–2027 学年四年级上** 现行书，不是旧 PEP「My classroom」：

| 科 | 版本 |
|----|------|
| 语文 | 统编四上（观潮 / 走月亮 / 《夜间飞行的秘密》） |
| 数学 | 人教四上（大数 → 公顷 → 角 → 三位数乘两位数） |
| 英语 | **人教 PEP 2024 审定新教材** Unit 1 *Helping at home* |

课文全文有版权，库里只放目录、语文要素、公开古诗、词语/词表和四年级允许的方法。最终以孩子手里的课本为准。

判官是本地规则（计算器 / 原文逐字 / 本单元词表），不是大模型打分。人教四上讲解里出现「方程 / 未知数」会直接停。

## 语音讲解（你的声音）

本机没有现成的爸爸声样，不能凭空克隆。

1. 打开「爸爸的声音」
2. 对着十条讲解底稿各读一遍（存在**这台浏览器**，不上传仓库）
3. 晚上点「听讲解」：录过的技能播你的声音，没录的用系统中文声

克隆第三方音色需要你本人的授权音频；录的是你自己的讲解句，即可直接播。
