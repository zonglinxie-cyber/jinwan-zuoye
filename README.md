# 今晚作业

四年级作业的批改、讲解和记忆。拍今晚老师布置的那张纸，**能验才判**，记下她错在哪，先钉住一步，再想开一点。孩子主操作，大人可插一句或稍后看一眼。

线上试玩：

https://zonglinxie-cyber.github.io/jinwan-zuoye/

本机：

```bash
cd 今晚作业
python3 -m http.server 3002
```

打开 http://127.0.0.1:3002

## 做什么

| 块 | 做什么 | 不做什么 |
|---|---|---|
| **批改** | 本地规则验算 / 对课文原词 / 对本单元词表 | 大模型打分、搜题给答案 |
| **讲解** | 先说错在哪，只钉一步，再举一反三想开 | 报这题得数、提前讲方程 |
| **记忆** | 错题记：哪一天、哪一科、错在哪、本上写了什么 | 正确率、周报、成长日记 |

「成长镜」那条交作业仪式不在这里。这边只服务今晚这张纸。

## 2026 秋教材包

仓库里的 `kb/` 对齐 **2026–2027 学年四年级上** 现行书，不是旧 PEP「My classroom」：

| 科 | 版本 |
|----|------|
| 语文 | 统编四上（观潮 / 走月亮 / 《夜间飞行的秘密》） |
| 数学 | 人教四上（大数 → 公顷 → 角 → 三位数乘两位数） |
| 英语 | **人教 PEP 2024 审定新教材** Unit 1 *Helping at home* |

课文全文有版权，库里只放目录、语文要素、公开古诗、词语/词表和四年级允许的方法。最终以孩子手里的课本为准。

人教四上讲解里出现「方程 / 未知数」会直接停。想开一点也不会写出当前这题的得数。

## 语音讲解（你的声音）

1. 打开「爸爸的声音」
2. 对着十条讲解底稿各读一遍（存在**这台浏览器**，不上传仓库）
3. 晚上点「听这一步」：录过的技能播你的声音，没录的用系统中文声

## 不做

正确率、周报、搜题给答案、自动出题海、交作业仪式、账号云同步。

作业照片、录音和错题记只在本机。
